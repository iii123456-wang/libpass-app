# LibPass · 备考打卡

单文件离线网页应用:`index.html`(无需安装、无需联网、无任何依赖)。

## 快速开始

> **线上地址(推荐,随时随地可用):https://iii123456-wang.github.io/libpass-app/**


- **最简单**:双击 `index.html`,浏览器直接打开即可使用。
- **推荐(解锁全部能力)**:通过 HTTP 访问,定位、提醒、添加到主屏幕才完整生效:
  - 本机:`python -m http.server 8410` 后访问 `http://localhost:8410/`
  - 或部署到 GitHub Pages / Vercel 等任意静态托管,得到一个随时可打开的网址。

## 功能一览

| 模块 | 说明 |
|---|---|
| 🏛️ 每日打卡 | 到图书馆/教学楼/自习室自动识别定位并提醒;定位不可用时可手动选择地点打卡;连续/累计天数统计 |
| 📷 拍照记录 | 拍照或选相册,自动压缩后存入本机 IndexedDB;按日归档、灯箱查看 |
| 🎭 心态记录 | 16 个表情一键记录今天的心态,14 天心态轨迹条 |
| 📓 四类笔记 | 行测/申论/错题/灵感四个分类(均可重命名),支持跨分类搜索 |
| 🎯🗓️ 双线时间轴 | 长期目标甘特图(带"今天"竖线)+ 短期任务清单(逾期自动标红、一键顺延到今天) |
| ⏳ 专注计时 | 25/45/60/90 分钟或自定义;切出页面自动计为中断并生成专注纯度评分;满 60 分钟自动提醒分段休息 |
| 📊 数据复盘 | 12 周打卡热力图、今日四格环形进度、7 天专注趋势柱状图、照片档案 |
| 🧠 每日一句 | 144 句励志/搞怪语(法科生专属 100 句 + 通用 44 句),每天固定一句,可手动换 |
| ⭐ 游戏化激励 | 打卡/专注时长兑换糖果 🍬;每日免费盲盒 + 糖果开盒,随机弹出可开盲盒,开出金币、糖果与稀有考点卡;金币银行记录累计存入与流水;考点卡册可集齐 18 张 |
| ⌚ 手表视图 | 设置 → 手表视图预览(或网址后加 `#watch`) |

## 多端兼容说明

- **iPhone**:Safari 打开 → 分享 →「添加到主屏幕」,即像 App 一样全屏运行(需 iOS 16.4+ 且通过 https 访问才有系统通知)。
- **华为平板/手机**:浏览器直接打开,布局自适应宽屏。
- **Apple Watch**:watchOS 无法运行网页,正式手表端需原生应用开发;本应用提供手表组件样式的预览视图(设置 → 手表视图预览),连续天数、倒计时、打卡与快捷心态已按表盘尺寸设计。

## 数据与隐私

- 所有数据仅保存在**本机浏览器**(localStorage + IndexedDB),不上传任何服务器。
- 照片经压缩(最长边 1280px、JPEG 82%)后存储。
- 换设备/清浏览器前,先在「设置 → 导出数据」备份 JSON(可选包含照片),新设备用「导入」恢复。
- 浏览器"无痕模式"下 IndexedDB 可能不可用,请正常模式使用。

## 自定义

- 考试名称与日期:设置 → 用于顶部倒计时。
- 应用图标:应用内 logo 为莫兰迪暖灰渐变底 + 雾霾粉紫光斑(白色书页+对勾造型不变);独立图标文件在 `../libpass-icon/`(深绿版)仍可用于其他场合。
- 地点坐标:设置 → 地点管理 →「取当前位置」在校准点(如图书馆门口)按下,半径 50–800m 可调。
- 每日一句:编辑 `index.html` 中 `QUOTES` 数组(每条 `[文本, 出处, 类型]`,现有 144 条)。
- 考点卡:编辑 `CARDS` 数组(每条 `{id, s:科目, e:表情, t:考点}`,现有 18 张)。
- 兑换比例:奖励模块中「每次打卡 = 10🍬」「每 25 分钟专注 = 10🍬」「盲盒 = 30🍬」可在 `renderRewards`/兑换逻辑处调整。
- 默认笔记分类:编辑 `S.cats` 初始值(应用内重命名仅对本机生效)。
